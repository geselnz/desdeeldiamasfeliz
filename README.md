# 🇦🇷 ¿Desde cuándo Argentina es campeona del mundo?

Este proyecto muestra de manera simple y precisa desde cuándo la Selección Argentina de fútbol es campeona del mundo.

## 🏆 ¿Qué hace este proyecto?

Este repositorio tiene como objetivo:

- Informar cuánto tiempo ha pasado desde el último título mundial de Argentina.
- Mostrar una cuenta regresiva o progresiva desde el **18 de diciembre de 2022**.
- Celebrar y mantener viva la memoria del campeonato mundial obtenido en Qatar 2022.
- Servir como base para un sitio web, script o widget embebible.

## 📅 Contexto

Argentina ganó su **tercera Copa del Mundo** el *18 de diciembre de 2022*, en una histórica final contra Francia.  
Desde entonces, el país celebra este logro con orgullo y emoción.

## 🔧 Tecnologías usadas

- HTML / CSS / JavaScript (para una versión web)
